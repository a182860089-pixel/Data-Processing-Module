# 🔄 异步轮询测试 - 快速参考

## 访问方式
在应用顶部标签栏点击 **🔄 异步轮询测试** 按钮

## 核心参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 轮询间隔 | 100-5000ms | 1000ms | 检查任务状态的频率 |
| 模拟时长 | 1-30s | 5s | 任务完成所需时间 |
| 任务数量 | 1-10 | 3 | 同时运行的任务数 |
| 自动模式 | On/Off | Off | 依次启动或同时启动 |

## 快速操作

```
【启动轮询测试】→ 创建并运行任务
【停止所有轮询】→ 暂停所有活动任务
【手动轮询】→ 对单个任务进行一次检查
【重置】→ 删除单个任务
```

## 性能指标

```
📊 指标面板
├─ 总轮询次数      : 所有轮询请求总数
├─ 成功轮询        : 成功的轮询次数 ✅
├─ 失败轮询        : 失败的轮询次数 ❌
├─ 平均轮询间隔    : 平均每次轮询耗时
├─ 总耗时          : 完成所有任务耗时
└─ 活跃任务        : 正在进行的任务数
```

## 任务状态流

```
⏳ pending (等待中)
   ↓ [启动轮询]
⚙️  processing (处理中)
   ├─ [轮询中]
   └─ [进度 >= 100%]
✅ completed (已完成) ← [正常]
❌ failed (失败) ← [出错/超时]
```

## 常见问题

### Q: 任务一直不完成？
A: 检查 `模拟时长` 是否足够长，轮询间隔是否合理

### Q: 轮询次数太多？
A: 增加 `轮询间隔` 值，或检查网络延迟

### Q: 想测试超时？
A: 设置很长的 `模拟时长`（>30s），观察超时处理

### Q: 如何对比不同配置？
A: 记录指标数据后，改变配置重新测试，对比数据变化

## 计算公式

### 预期轮询次数
```
次数 = 模拟时长 / 轮询间隔
示例: 5000ms / 1000ms = 5 次
```

### 预期总时间
```
总时间 ≈ 模拟时长（实际可能略长）
示例: 5000ms ≈ 5 秒
```

### 平均轮询间隔
```
平均 = 所有轮询耗时总和 / 轮询次数
示例: 50ms（包括网络和计算延迟）
```

### 高级使用 - 自定义轮询
```typescript
import { useAsyncPolling } from '@/composables/useAsyncPolling'

const { createTask, startPolling } = useAsyncPolling()

// 创建任务
const task = createTask('API 任务')

// 定义轮询函数
const pollFn = async () => {
  const res = await fetch('/api/task/progress')
  const data = await res.json()
  return data.progress // 返回 0-100
}

// 启动轮询（每 500ms 检查一次，30s 超时）
startPolling(task, pollFn, 500, 30000)
```
